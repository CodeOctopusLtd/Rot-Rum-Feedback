# Rot & Rum Feedback

Reviewed bug summaries, suggestions and progress for Rot & Rum.

Follow the [public feedback board](https://github.com/orgs/CodeOctopusLtd/projects/17) to see published feedback and its status.

Reports submitted through the game's reporting flow are intended for private review. Only approved summaries are published here. Original reports and screenshots are not automatically published.

Anything you post directly in this repository is public, including issue text, comments and attachments.
