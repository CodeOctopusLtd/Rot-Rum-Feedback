# Rot & Rum Feedback

Public bug reports, suggestions and progress for Rot & Rum.

Follow the [public feedback board](https://github.com/orgs/CodeOctopusLtd/projects/17) to see feedback and its status.

The game's reporting flow captures the game view for preview or removal, saves a local report, and opens a prepared GitHub issue. Sign in to GitHub, attach the saved screenshot if you want to include it, review the report and select Submit new issue. Opening the browser does not submit a report.

Reports, comments and attached screenshots submitted here are public. Review what you include before submitting.
